# Parking Single Page Application

A single page web application built with PHP, MySQL, Bootstrap, and jQuery for managing car parking records, vehicle check-ins, charges, and parking status.

## Features
- Add new parking entries (Car Number, Car Name, Owner Name, Charges)
- View real-time list of parked vehicles
- Delete/checkout parking records
- Responsive interface using Bootstrap 4 and jQuery

## Tech Stack
- **Backend:** PHP
- **Database:** MySQL
- **Frontend:** HTML5, CSS3, Bootstrap 4, jQuery
